# Decreto nº 4176/1982

DECRETO Nº 4.176, DE 17 DE MARÇO DE 1982

Atribui denominação a Logradouros públicos do Conjunto Habitacional Celso Machado.

O Prefeito de Belo Horizonte, no uso de suas atribuições e

Considerando as solicitações dos moradores do Conjunto Habitacional Celso Machado, decreta:

**Art.1º** - As ruas do Conjunto Habitacional Celso Machado, identificadas por ordem alfabética cardinal, passam a ter as seguintes designações constantes do item abaixo:

I - Rua São José da Safira para a Rua A;

II - Rua Sericita para a Rua B;

III - Rua Orizônia para a Rua C;

IV - Rua Ibicaraí para a Rua D;

V - Rua Edem para a Rua E;

VI - Rua Parandá para a Rua F;

VII - Rua Piranguçu para a Rua G;

VIII - Rua Guapuã para a Rua H;

IX - Rua Afluentes para a Rua I;

X - Rua Setentrional para a Rua J;

XI - Rua Aurelândia para a Rua K;

XII - Rua Jabaquara para a Rua L;

XIII - Rua Taquaraçu para a Rua M;

XIV - Rua Santanésia para a Rua N;

XV - Rua Ouvidor para a Rua O;

XVI - Rua Itagimirim para a Rua P;

XVII - Rua Cariacica para a Rua Q;

XVIII - Rua Pontalina para a Rua R;

XIX - Rua Ibatiba para a Rua R1;

XX - Rua Brasilândia para a Rua S;

XXI - Rua Abatiá para a Rua T;

XXII - Rua Lídice para a Rua U;

XXIII - Rua Ourinhos para a Rua V;

XXIV - Rua Santana da Vargem para a Rua W;

XXV - Rua Cascatinha para a Rua X;

XXVI - Rua Guaramirim para a Rua Y;

XXVII - Rua Ocidental para a Rua Z;

XXVIII - Rua Tocantins para a Rua 2;

XXIX - Rua Paraúna para a Rua 3;

XXX - Rua Cristalina para a Rua 4.

**Art. 2º** - Os órgãos competentes da Municipalidade promoverão a colocação das placas indicativas, bem como a necessária comunicação à Empresa Brasileira de Correios e Telégrafos.

**Art. 3º** - Revogadas as disposições em contrário, este Decreto entra em vigor na data de sua publicação.

Belo Horizonte, 17 de março de 1982

Maurício de Freitas Teixeira Campos

Prefeito de Belo Horizonte

Martim Francisco Coelho de Andrada

Vice-Presidente do Conselho Municipal de Planejamento do Desenvolvimento
