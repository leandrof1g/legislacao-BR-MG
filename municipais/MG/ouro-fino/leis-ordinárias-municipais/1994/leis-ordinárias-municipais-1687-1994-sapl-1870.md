LEI 1,687/94

RECONHECE A DATA DA IMPLANTAÇÃO DO DISTRITO DE CRISOLIA.

Francisco de Paula Menezes Rossi, Prefeito do Município de Ouro Fino. Estado de Minas Gerais. faz saber que a Câmara Municipal aprova e ele sanciona a seguinte Lei: |

**Artigo 10** - Fica reconhecido o dia 25 de novembro como sendo| a data oficial da Implantação do Distrito de Crisólia.

| | | |

**Artigo 20** - Revogadas as disposições em contrário. esta Lei entra em vigor na data da sua publicação.

| | | | | | | |

Prefeitura do Município de Ouro Fino(MG), 24 de outubro de 1.994.

FOR

Francisco de Paula Menezes Rossi | Prefeito Municipal |
