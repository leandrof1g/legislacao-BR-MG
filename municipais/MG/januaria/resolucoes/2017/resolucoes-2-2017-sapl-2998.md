# Resolução nº 2, de 16/02/2017

RESOLUÇÃO Nº 002/2017 ESTABELECE O CALENDÁRIO ANUAL DAS REUNIÕES ORDINÁRIAS CONJUNTAS DAS COMISSÕES PERMANENTES DA CÂMARA MUNICIPAL DE JANUÁRIA PARA O EXERCÍCIO DE 2017.
