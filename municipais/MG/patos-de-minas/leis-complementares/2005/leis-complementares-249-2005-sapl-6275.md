# Lei Complementar nº 249, de 15/12/2005

LEI COMPLEMENTAR Nº 249 – DE 15 DE DEZEMBRO DE 2005

Aumenta o número de cargos de Técnico de Nível Superior I/ Psicólogo Clínico

O Povo do Município de Patos de Minas, Estado de Minas Gerais, por seus representantes, aprovou, e, eu em seu nome, sanciono a seguinte Lei Complementar:

**Art. 1º** Para atender as necessidades da Administração Municipal, o cargo de Técnico de Nível Superior I/Psicólogo Clínico, criado pela Lei Complementar Nº 018/93, tem seu número aumentado da seguinte forma:

| | | | |

|CARGO |Nº ATUAL DE CARGOS |Nº DE CARGOS AUMENTADOS |TOTAL DE CARGOS |

| | | | |

|TÉCNICO DE NÍVEL SUPERIOR I/ PSICÓLOGO CLÍNICO | | | |

| |12 |02 |14 |

**Art. 2º** A forma de provimento, as atribuições e os níveis de vencimento do cargo a que se refere o artigo anterior, estão estabelecidos na Lei Complementar nº 018/93.

**Art. 3º** As despesas decorrentes desta Lei correrão à conta de dotações próprias do Orçamento Municipal vigente.

**Art. 4º** Esta Lei Complementar entra em vigor na data de sua publicação, com efeitos retroativos a 25 de novembro de 2005.
