# Lei Complementar nº 252, de 29/12/2005

LEI COMPLEMENTAR Nº 252 – DE 29 DE DEZEMBRO DE 2005

Aumenta o número de cargos que identifica

O Povo do Município de Patos de Minas, Estado de Minas Gerais, por seus representantes, aprovou, e, eu em seu nome, sanciono a seguinte Lei:

**Art. 1º** Para atender as necessidades da Administração Municipal, os cargos de Técnico de Nível Superior I/Psicólogo Clínico, Assistente Social, Contador, Engenheiro Civil e Arquiteto, criados pela LC Nº 018/1993, têm seus números aumentados da seguinte forma:

| CARGO |Nº ATUAL DE CARGOS |Nº DE CARGOS AUMENTADOS |TOTAL DE CARGOS |

|TÉCNICO DE NÍVEL SUPERIOR I / PSICÓLOGO CLÍNICO | | | |

| |14 |5 |19 |

|TÉCNICO DE NÍVEL SUPERIOR I / ASSISTENTE SOCIAL | | | |

| |19 |5 |24 |

|TÉCNICO DE NÍVEL SUPERIOR I / CONTADOR | | | |

| |1 |5 |6 |

|TÉCNICO DE NÍVEL SUPERIOR I / ENGENHEIRO CIVIL | | | |

| |7 |5 |12 |

|TÉCNICO DE NÍVEL SUPERIOR I / ARQUITETO | | | |

| |4 |5 |9 |

**Art. 2º** A forma de provimento, as atribuições e os níveis de vencimento dos cargos referidos no artigo anterior, estão estabelecidos na Lei Complementar nº 018/1993.

**Art. 3º** As despesas decorrentes do disposto no art. 1º correrão à conta de dotações próprias do Orçamento Municipal vigente.

**Art. 4º** Esta Lei Complementar entra em vigor na data de sua publicação.

Prefeitura Municipal de Patos de Minas, 29 de dezembro de 2005, 116° ano da República e 137° ano do Município
