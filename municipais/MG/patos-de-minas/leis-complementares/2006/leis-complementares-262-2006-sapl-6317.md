# Lei Complementar nº 262, de 28/06/2006

LEI COMPLEMENTAR Nº 262, DE 28 DE JUNHO DE 2006.

Aumenta o número de cargos de Diretor de Órgãos Municipais e Auxiliar de Serviços.

O Povo do Município de Patos de Minas, Estado de Minas Gerais, por seus representantes, aprovou, e, eu em seu nome, sanciono a seguinte Lei Complementar:

**Art. 1º** Para atender às necessidades da Administração Municipal, os cargos de Diretor de Órgãos Municipais e Auxiliar de Serviços, criados pela Lei Complementar Nº 018/93, têm seu número aumentado da seguinte forma:

| | | | |

|CARGO |Nº ATUAL DE CARGOS |Nº DE CARGOS AUMENTADOS |TOTAL DE CARGOS |

| | | | |

|DIRETOR DE ÓRGÃOS MUNICIPAIS |10 |5 |15 |

| | | | |

|AUXILIAR DE SERVIÇOS |350 |10 |360 |

**Art. 2º** A forma de provimento, as atribuições e os níveis de vencimento do cargos a que se refere o artigo anterior estão estabelecidos na Lei Complementar nº 018/93.

**Art. 3º** As despesas decorrentes desta Lei correrão à conta de dotações próprias do Orçamento Municipal vigente.

**Art. 4º** Esta Lei Complementar entra em vigor na data de sua publicação.

Prefeitura Municipal de Patos de Minas, 28 de junho de 2006, 116° ano da República e 138° ano do Município.
