# Lei Ordinária nº 3175, de 18/11/1983

LEI Nº 3175, DE 18 DE NOVEMBRO DE 1983.

CRIA O QUADRO DE TARIFAS DE ÁGUA E ESGOTO NO SAAE E DÁ OUTRAS PROVIDÊNCIAS.

A Câmara de Vereadores de Sete Lagoas votou e eu sanciono a seguinte lei:

**Art. 1º** Fica criado no Serviço Autônomo de Água e Esgoto - SAAE, o seguinte quadro de tarifas de água e esgoto. ............................................................. | I - TARIFA DE ÁGUA | | | |CATEGORIA DOMICILIAR | | + | |1ª Faixa de Consumo |0 a 10m³ | | | | |2ª Faixa de Consumo |11 a 20m³ | | | | |3ª Faixa de Consumo |21 a 30m³ | | | | |4ª Faixa de Consumo |31 a 40m³ | | | | |5ª Faixa de Consumo |41 a 50m³ | | | | |6ª Faixa de Consumo |51 a 70m³ | | | | |7ª Faixa de Consumo |71 a 100m³ | | | | |8ª Faixa de Consumo |101 a 200m³ | | | | |9ª Faixa de Consumo |201 acima | | + | |CATEGORIA COMERCIAL | | + | |1ª Faixa de Consumo |0 a 30m³ | | | | |2ª Faixa de Consumo |31 a 100m³ | | | | |3ª Faixa de Consumo |101 acima | | + | |CATEGORIA INDUSTRIAL | | + | |1ª Faixa de Consumo |0 a 30m³ | | | | |2ª Faixa de Consumo |31 a 100m³ | | | | |3ª Faixa de Consumo |101 acima | |\_ ................................| |

II - TARIFA DE ESGOTO

Igual em todas as categorias da tarifa de água a 80% (oitenta por cento) sobre o consumo real de água.

**Art. 2º** Ficam, revogados os seguintes artigos, incisos e alíneas da Lei 1329 de 26 de novembro de 1968: Alínea "e", inciso I, do artigo 39, artigo 9º; artigo 10, seus incisos e parágrafo; artigo 11; artigo 12, seus incisos e alíneas.

**Art. 3º** Revogadas as disposições em contrário esta lei entrará em vigor na data de sua publicação.

Prefeitura Municipal de Sete Lagoas, 18 de novembro de 1983.

MARCELO CECÉ VASCONCELOS DE OLIVEIRA Prefeito Municipal
