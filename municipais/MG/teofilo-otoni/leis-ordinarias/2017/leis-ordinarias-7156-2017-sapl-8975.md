# Lei Ordinária nº 7156, de 09/08/2017

**Lei nº 7.156**

Autoriza o Poder Executivo a implementar o software Dengue Report junto ao combate de endemias

A Câmara Municipal de Teófilo Otoni aprova:

**Art. 1º.** Fica o Poder Executivo autorizado a instituir no Município de Teófilo Otoni, o software Dengue Report para dinamizar as ações de combate a endemias

**Art.2º.** O Poder Executivo, realizará treinamento para os servidores que atuarão em campo e diretamente ligados a coleta de dados.

**Art.3º.** As despesas decorrentes da execução desta lei, correrão por conta das dotações orçamentárias próprias, suplementadas, se necessário.

**Art.4º.** Esta lei entrará em vigor na data de sua publicação.

Câmara Municipal de Teófilo Otoni-MG, 09 de agosto de 2017

**Fábio Lemes de Souza**
