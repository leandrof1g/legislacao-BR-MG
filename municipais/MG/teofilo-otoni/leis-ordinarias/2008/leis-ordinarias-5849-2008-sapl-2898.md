# Lei Ordinária nº 5849, de 25/06/2008

Lei nº 5.849

Autoriza alienação de Ações

A Câmara Municipal de Teófilo Otoni aprova:

**Art. 1º** Fica o Município de Teófilo Otoni autorizado a alienar Ações de sua propriedade, a seguir discriminadas:

a) Brasil Telecon Participação, código de negociação nº #BRTP3.

b) Brasil Telecon Participação, código de negociação nº #BRTP4.

c) Contax, código de negociação nº CTAX3.

d) Contax, código de negociação nº CTAX4.

e) Embratel Participação, código de negociação nº EBTP3.

f) Embratel Participação, código de negociação nº EBTP4.

g) Petrobrás, código de negociação nº #PETR3.

h) Petrobrás, código de negociação nº #PETR4.

i) Telebrás, código de negociação nº TELB3.

j) Telebrás, código de negociação nº TELB4.

k) Telemar, código de negociação nº #TNLP3.

l) Telemar, código de negociação nº #TNLP4.

m) Telemar Norte Leste, código de negociação nº TMAR3.

n) Telemar Norte Leste, código de negociação nº #TMAR5.

o) Telemig Celular, código de negociação nº TMGC3.

p) Telemig Celular, código de negociação nº TMGC7.

q) Telemig Participação, código de negociação nº TMCP3.

r) Telemig Participação, código de negociação nº #TMCP4.

s) Telesp, código de negociação nº TLPP3.

t) Telesp, código de negociação nº #TLPP4.

u) Tim participação S/A, código de negociação nº #TCSL3.

v) Tim participação S/A, código de negociação nº #TCSL4.

w) Vivo, código de negociação nº VIVO3.

x) Vivo, código de negociação nº #VIVO4.

**Art. 2º** O montante auferido com a alienação das Ações discriminadas no artigo 1º desta lei, será empregado na reestruturação das estradas vicinais.

**Art. 3º** Esta lei entra em vigor na data de sua publicação, revogadas as disposições em contrário.

Câmara Municipal de Teófilo Otoni, 25 de junho de 2008.

Northon Neiva Diamantino

Presidente da Câmara Municipal

Autoria: Executivo Municipal
